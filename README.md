# 股票智研 (Stock Lens)

输入一个股票代码，实时拉取行情、K 线、财报、资金流、龙虎榜、解禁与新闻，先由本地量化规则引擎做多维评分，再由 **DeepSeek + Kimi 双模型**生成深度研报。支持 A 股 / 港股 / 美股。

> ⚠️ 本项目输出内容仅为基于公开数据的分析参考，**不构成投资建议**。市场有风险，投资需谨慎。

## 功能

- **多市场代码识别**：A 股 6 位数字（600519）、港股 5 位（00700）、美股字母（AAPL）
- **实时数据**：行情 / 估值（PE·PB·市值·换手）/ 160 日 K 线 / 主力资金流（当日·5 日·10 日）/ 近 6 期财报 / 要闻（含利好利空情绪标注）/ 公司公告
- **规则引擎多维评分**：趋势、动量、资金、估值、基本面、消息面、A 股特色共 7 个维度，综合评分 -100~+100，输出五档评级与「多空辩论」及条件化买卖参考
- **A 股特色透视**：涨跌停价（主板 10% / 科创创业 20% / 北交所 30% / ST 5%）、板块轮动位置、龙虎榜热钱、限售解禁日程、T+1 制度提醒
- **AI 深度研报（双模型）**：Kimi 通读新闻公告做消息面逐条精读，DeepSeek 撰写首席分析师级综合研报（核心逻辑、四维解读、风险、结论）
- **访问令牌门**：首次访问输入口令，验证后浏览器本地记住，服务端 API 二次校验

## 目录结构

```
stock-lens/
├── server.js            # Node.js 零依赖后端（数据源 + 规则引擎 + HTTP 服务）
├── llm.js               # 双模型 AI 研报管线（DeepSeek × Kimi）
├── llm.config.example.json  # 配置样例（复制为 llm.config.json 后填写密钥）
├── public/
│   ├── index.html       # 页面结构
│   ├── style.css        # 样式（红涨绿跌）
│   ├── app.js           # 前端渲染 + 图表 + 令牌门
│   └── vendor/echarts.min.js
├── DESIGN.md            # 架构设计文档
├── DEPLOYMENT.md        # 部署文档（含公网隧道）
└── docs/BKM-项目实战教程.md  # WorkBuddy 实战教程（如何用 AI 生成本项目）
```

## 快速开始

```bash
# 1. 安装 Node.js ≥ 18（本项目零 npm 依赖）
# 2. 配置密钥
cp llm.config.example.json llm.config.json
#    编辑 llm.config.json，填入访问口令、DeepSeek Key、Kimi Key

# 3. 启动
node server.js
#    打开 http://127.0.0.1:8630 ，输入访问口令后即可使用
```

> 不填 `accessToken` 字段则关闭口令门；不填两个模型 Key 则 AI 研报不可用，但规则引擎分析不受影响。
